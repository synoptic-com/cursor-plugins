# Synoptic plugins for Cursor

Cursor plugins for [Synoptic](https://www.synoptic.com/) news feeds and source monitoring.

| Plugin | Description |
| --- | --- |
| [synoptic](plugins/synoptic) | Follow live feeds from Telegram and GitHub to press releases, SEC filings, IPOs, court dockets and economic releases, and publish your own feeds with Synoptic. |

Install it from the Cursor Marketplace, then open **Settings → MCP**, select **synoptic** and sign in. See the [plugin README](plugins/synoptic/README.md) for permissions, data handling and troubleshooting.
